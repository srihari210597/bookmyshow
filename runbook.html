🎬 BookMyShow IMAX Watcher

Runbook — INOX LUXE Velachery · The Odyssey · Mon 20 Jul 2026 · IMAX

Prerequisites

  • macOS with Python 3.11+ (python3 --version)
  • Homebrew (for Chromium dependencies if needed)
  • Internet connection (obviously)

Setup (Steps 1–5)

Step 1 — Create a virtual environment

cd ~/Desktop/"Book MY"
python3 -m venv .venv
source .venv/bin/activate

Step 2 — Install dependencies

pip install playwright
playwright install chromium

If you pick ntfy.sh later, also: pip install requests

Step 3 — Configure Gmail alert

Open bms_theatre_watch.py and fill in the three fields at the top of notify():

GMAIL_USER = "you@gmail.com"
GMAIL_APP_PASSWORD = "xxxx xxxx xxxx xxxx"
TO_EMAIL = "you@gmail.com"

To get an App Password:

  1. Go to myaccount.google.com/apppasswords
  2. Sign in, select app "Mail", device "Mac"
  3. Copy the 16-character password into GMAIL_APP_PASSWORD

2FA must be enabled on your Google account for App Passwords to appear.

Step 4 — Dry-run test

python bms_theatre_watch.py --dry-run

Expect: "No IMAX showtimes yet for LUXE" (since Monday isn't listed yet). Confirms Playwright + page load work.

Step 5 — Manual real-run test (optional)

Temporarily change THEATRE_KEYWORD to "PVR" (which already has Monday shows) and run without --dry-run. Verify your alert fires. Then revert to "LUXE" and delete .bms_alert_sent.

Scheduling (Steps 6–8)

Step 6 — Install the cron job

crontab -e

Add this line (runs every 5 minutes):

*/5 * * * * cd ~/Desktop/"Book MY" && .venv/bin/python bms_theatre_watch.py >> cron.log 2>&1

Step 7 — Grant cron Full Disk Access

System Settings → Privacy & Security → Full Disk Access → add /usr/sbin/cron.

Without this, macOS may silently block network access from cron.

Step 8 — Prevent sleep (critical)

cron does NOT run while your Mac sleeps and does NOT replay missed jobs on wake.

Option A — keep awake overnight:

caffeinate -s &

Option B — use a cloud VM (even a free-tier EC2 or a $5 DigitalOcean droplet). Copy the project, install Playwright there, and add the same cron entry.

After Booking (Steps 9–10)

Step 9 — Disable the watcher

# Remove cron entry
crontab -e   # delete the line

# Or just stop caffeinate
killall caffeinate

Step 10 — Reset if needed

To re-arm the watcher (e.g., if you want to watch a different date):

rm .bms_alert_sent
# Edit TARGET_URL and date in bms_theatre_watch.py
# Re-add cron entry
